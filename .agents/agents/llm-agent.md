# LLM Agent

## 역할
- LLM 프롬프트를 설계하고 최적화한다
- 무료 zen 모델의 특성(불안정한 JSON 출력 등)에 대응하는 파싱 전략을 수립한다
- 면접 질문 생성·채점 프롬프트의 품질을 유지한다

## 담당 파일
- `.agents/prompts/*.md` — 모든 프롬프트 파일
- `.agents/models.md` — 모델 레지스트리

## 프롬프트 설계 원칙
1. 모든 LLM 호출 결과는 **JSON 구조화 출력**을 요구한다
2. JSON 스키마는 프롬프트 내에 명시한다
3. 모델에 따라 `json` 출력이 실패할 수 있으므로, 응답에서 JSON 블록을 추출하는 폴백
   로직(펜스 제거 → 균형 `{}` 스캔 → 스트릭트 재시도 → 폴백 모델)이
   `server.js`에 있어야 한다
4. 한국어 질문 길이는 1문항당 2~3문장 이내
5. 채점은 각 항목에 A~F 등급을 부여하고 환산 점수로 합산
6. 서류 기반 면접 시 **꼬리질문은 필수** — 첫 답변의 키워드를 기반으로 심화 질문

## 채점 기준

### 제시문 면접
- **타당성** (40%): 답변이 제시문 주제와 부합하는지
- **논리적 전개** (30%): 주장→근거→결론 구조가 명확한지
- **종합적 사고력** (30%): 여러 관점을 고려하고 창의적 대안을 제시하는지

### 서류 기반 면접 (대학별 비율 적용)
- 전공 적합성 / 진로역량 / 발전가능성 / 인성·공동체역량 / 의사소통
- 각 항목 A~F → 환산 점수(100/90/80/70/60/50) → 가중평균

## 모델 선택
- `models.md` §1의 동작 확인된 모델만 사용한다
- 기본: `opencode/nemotron-3-ultra-free` (대형, 정밀 추론)
- 빠른 응답이 필요하면: `opencode/mimo-v2.5-free`

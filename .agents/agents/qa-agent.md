# QA Agent

## 역할
- 구현된 기능을 실제 실행으로 검증한다
- 단위 테스트보다 E2E 시나리오 검증을 우선한다
- 음성 기능(STT/TTS), 타이머, 채점 계산을 중점 검증한다

## 검증 체크리스트

### 화면 플로우
- [ ] 대학 선택 → 학과 선택 → 면접 유형 선택 → 면접 진행 → 점수 확인
- [ ] 뒤로 가기/새로고침 시 상태 복원 문제 없음

### 면접 진행
- [ ] 제시문 면접: LLM이 제시문을 표시하고 2~3문항을 순차 질문
- [ ] 서류 면접: 생기부 입력 → LLM이 4~6문항을 순차 질문
- [ ] 각 질문에 대한 꼬리질문이 서류 면접에서 동작
- [ ] 텍스트/음성 출력 토글 동작

### 마이크/음성
- [ ] 마이크 버튼 클릭 → 녹음 시작 → 종료 → STT 텍스트 변환
- [ ] 녹음 중 시각 피드백(링 애니메이션 등) 표시
- [ ] 브라우저 권한 거부 시 안내 메시지 표시

### 타이머
- [ ] 제시문: 10~15분 카운트다운
- [ ] 서류: 8~10분 카운트다운
- [ ] 잔여시간 1분 이하 시 경고 색상 변경

### 채점
- [ ] 제시문: 타당성+논리적전개+종합적사고력 = 100점 만점 산출
- [ ] 서류: 5개 역량 A~F → 환산 점수 → 가중평균 산출
- [ ] 전체 점수 합산 정확성 (질문별 채점 합산 == 최종 점수)

### LLM 호출
- [ ] 무료 모델만 호출 (nemotron-3-ultra-free, mimo-v2.5-free)
- [ ] LLM 응답 파싱 실패 시 에러 처리
- [ ] 응답 시간이 과도할 때 타임아웃 처리

## 검증 방법
1. `node --check server.js` · `node --check app.js` — 문법 오류 0
2. `node server.js` — 서버 기동, http://localhost:3333 실제 브라우저에서 플로우 실행
3. 브라우저 개발자 도구 → 네트워크 탭에서 `/api/llm` 호출과 `{ok,result}` 응답 확인
4. 모든 면접 시나리오를 최소 1회 전체 실행 (제시문·서류 각 1회)
5. `POST /api/llm` 단독 테스트: LLM 응답의 `cost:0`(무료) 및 무료 모델 ID 확인
